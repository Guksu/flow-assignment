# 프로젝트 정책 연결

이 파일은 관리 도구가 갱신한다. 팀 소유 `docs/harness-rules.md`의 정책이 우선한다.

- 브랜치·업로드 범위와 검증 명령은 프로젝트 정책을 따른다. 이미 승인된 구현에 필요한 안전한 브랜치 준비를 다시 승인받지 않는다.
- 기록·인계·협업 절차는 팀 정책 또는 사용자 요청이 있을 때 적용한다. 양식이 있다는 이유만으로 작성하지 않는다.
- 훅은 등록된 도구 경로의 실수 방지 장치다. 앱 권한이나 저장소 보호를 대신하지 않는다. 민감정보의 실제 값은 읽거나 기록하지 않는다.
- 하네스 구조 검사와 제품 테스트를 구분하고, 실행하지 못한 검사를 명시한다.
