## 2. 공개 배포가 만드는 위험 (D)

과제는 "면접 당일 누구나 접속 가능한" 배포를 요구한다. 사이트에 누구나 들어올 수 있어야 한다는 뜻이지, 정책 편집을 인증 없이 열라는 요구는 아니다. 인증 없이 편집을 연 것은 평가자가 계정 없이 핵심 기능을 바로 시험하게 하려는 우리 결정(문답 #10)이다. 아래 위험은 이 조건과 결정이 합쳐져서 나온다.

2. **대조 검토**: 그다음 이 문서를 주고 "빠진 것, 판정이 틀린 것, 근거가 약하거나 사실이 틀린 것"만 지적하게 했다.

아래 표는 2번 결과를 하나씩 검증한 기록이다. Claude는 지적을 그대로 받지 않고 재현·원문 확인을 거쳤다. Codex의 1번 목록 전체는 여기 옮기지 않았다.
